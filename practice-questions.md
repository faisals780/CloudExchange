# Practice Questions

## DSA — STL Container Practice (Beginner Level)

1. Vector se duplicate elements remove karo.
2. Vector ko sort karke usme kisi element ko binary search se dhoondo.
3. Stack use karke check karo ki brackets balanced hain ya nahi — `(){}[]`.
4. Queue use karke ek simple task scheduler simulate karo (first come first serve).
5. Map (`std::map`) use karke ek string ke andar har character ki frequency count karo.
6. Set (`std::set`) use karke ek array se sirf unique elements print karo.
7. Vector of pairs use karke naam aur marks store karo, phir marks ke hisaab se sort karo.
8. Stack use karke ek number ko reverse karo (digit by digit).
9. Queue use karke printer jaisa system banao jisme tasks ek ke baad ek process hon.
10. Map use karke do arrays mein common elements dhoondo.

## OOP — Library Management (Step by Step)

1. `Book` class banao — data members: `title`, `author`, `isAvailable`.
2. `Book` class mein ek constructor banao jo title aur author set kare.
3. `Library` class banao jisme `vector<Book>` ho books store karne ke liye.
4. `Library` class mein `addBook()` function banao jo naya book vector mein add kare.
5. `Library` class mein `showBooks()` function banao jo saare books print kare.
6. `issueBook()` function add karo jo kisi book ka `isAvailable` false kare (agar available ho).
7. `returnBook()` function add karo jo `isAvailable` wapas true kare.
8. Main function mein Library object banao, 2-3 books add karo, unhe show, issue, aur return karke test karo.
